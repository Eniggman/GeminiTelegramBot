## 🔍 Инлайн-режим (Placeholder)

> Строки `2722-2843` — вызов через `@bot_name текст` в любом чате

### Как работает

1. Пользователь пишет `@bot_name вопрос` (без триггеров)
2. Бот показывает кнопку **«🔮 Спросить Gemini»** — API **не вызывается**
3. Юзер кликает → в чат идёт placeholder с кнопкой `⏳🔮 Генерирую ответ...`
4. `ChosenInlineResultHandler` ловит клик → вызывает Gemini API
5. Placeholder заменяется на **`<b>Gemini:</b> ответ`**, кнопка убирается

> ⚠️ **Требуется:** `/setinlinefeedback` → 100% в `@BotFather`

> ⚠️ **Важно:** `reply_markup` (InlineKeyboardMarkup) обязательна в InlineQueryResultArticle!
> Без неё Telegram не передаёт `inline_message_id` в `ChosenInlineResult`, и `edit_message_text` невозможен.

### Логика обработки

| Ситуация             | Реакция                                          |
|:---------------------|:-------------------------------------------------|
| Нет доступа          | Кнопка «Жми на меня» → переход в бота (`guide`) |
| Пустой запрос        | Подсказка: «Напишите вопрос»                     |
| Есть текст           | Кнопка «🔮 Спросить Gemini»                      |
| После клика          | `⏳🔮 Генерирую ответ...` → **`Gemini:`** ответ   |
| Таймаут              | `⏱️ Превышено время ожидания`                    |
| Ошибка               | `❌ Ошибка: текст`                                |

### Функции

| Функция                          | Строка | Назначение                        |
|:---------------------------------|:------:|:----------------------------------|
| `handle_inline_query()`          |  2722  | Показ кнопки (без API)            |
| `handle_chosen_inline_result()`  |  2789  | API-вызов + редактирование ответа |

### Параметры

| Параметр        | Значение                            |
|:----------------|:------------------------------------|
| Модель          | `flash` (фиксированная)            |
| Инструменты     | `google_search` + `url_context`     |
| Таймаут         | `TIMEOUT_MEDIUM` (90 сек)           |
| Кэш inline      | 0 сек (каждый запрос уникален)     |
