## ⚡ Быстрые команды (Префиксы)

> Команды с пометкой 📝 поддерживают **два режима**:
> - Без аргумента → включает **режим ожидания** (бот ждёт следующее сообщение)
> - С текстом через пробел → **мгновенное выполнение** в одном сообщении

| Префикс               | Действие                      | Через пробел | Пример                         |
|:----------------------|:------------------------------|:------------:|:-------------------------------|
| `п` / `про` / `pro`   | 💎 Переключить на Gemini Pro  |      —       | `п`                            |
| `ф` / `флеш` / `flash`| ⚡ Переключить на Gemini Flash |      —       | `ф`                            |
| `к` / `картинка`      | 🎨 Генерация изображения      |     📝      | `к красивый закат`             |
| `к про`               | 💎 Модель картинок → Pro      |      —       | `к про`                        |
| `к флеш`              | ⚡ Модель картинок → Flash     |      —       | `к флеш`                       |
| `пр` / `перевод`      | 🌐 Перевод текста/фото        |     📝      | `пр hello world`               |
| `р` / `редактировать` | ✏️ Режим редактирования фото  |      —       | `р`                            |
| `ю``ютуб` / `самари`  | 📺 YouTube саммари             |     📝      | `ю https://youtu.be/...`       |
| `превью` / `пре`      | 🖼️ YouTube превью             |     📝      | `превью https://youtu.be/...`  |
| `.`                   | 🧹 Сброс контекста            |      —       | `.`                            |
| `выход` / `exit`      | ⏹️ Выход из режима            |      —       | `выход`                        |

## 🔍 Инлайн-режим

> Вызов через `@bot_name текст` в любом чате

### Поддерживаемые команды

| Команда | Действие | Пример |
|:--------|:---------|:-------|
| `пр <текст>` / `перевод` | 🌐 Перевод на русский | `@bot пр hello world` |
| `ю <ссылка>` / `ютуб` | 📺 YouTube саммари | `@bot ю https://youtu.be/...` |
| `превью <ссылка>` / `пре` | 🖼️ YouTube превью | `@bot превью https://youtu.be/...` |
| `<любой текст>` | 🔮 Спросить Gemini | `@bot что такое квантовая физика` |

### Как работает

1. Пользователь пишет `@bot_name команда/вопрос`
2. `_parse_inline_command()` определяет тип команды по префиксу
3. Бот показывает кнопку — API **не вызывается**
4. Юзер кликает → в чат идёт placeholder (`⏳`)
5. `ChosenInlineResultHandler` → выполняет команду
6. Placeholder заменяется на результат

> ⚠️ **Требуется:** `/setinlinefeedback` → 100% в `@BotFather`

> ⚠️ **Важно:** `reply_markup` обязательна! Без неё Telegram не передаёт `inline_message_id`.

### Логика обработки

| Ситуация | Реакция |
|:---------|:--------|
| Нет доступа | Кнопка «Жми на меня» → переход в бота |
| Пустой запрос | Подсказка с доступными командами |
| `пр <текст>` | 🌐 Перевести → перевод через Flash |
| `ю <ссылка>` | 📺 Саммари → `summarize_youtube()` |
| `превью <ссылка>` | 🖼️ Превью → название + ссылка |
| Свободный текст | 🔮 Gemini → ответ с поиском |
| Ответ > 500 символов | `<blockquote expandable>` |

### Функции

| Функция | Назначение |
|:--------|:-----------|
| `_parse_inline_command()` | Парсер команд по префиксу |
| `handle_inline_query()` | Показ кнопок (без API) |
| `handle_chosen_inline_result()` | Выполнение + редактирование |

### Параметры

| Параметр | Значение |
|:---------|:---------|
| Модель | `flash` (фиксированная) |
| Инструменты | `google_search` + `url_context` (только Gemini) |
| Лимит ответа | 3800 символов (system_instruction) |
| Каомодзи | `ฅ≽^◕⩊◕^≼⊃━✦゜` (только Gemini) |
